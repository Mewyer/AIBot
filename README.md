# Telegram AI Chat Bot

Этот бот предоставляет доступ к мощной модели искусственного интеллекта Meta-Llama-3-70B через платформу DeepInfra. Пользователи могут общаться с ИИ, используя систему очков.

## Основные функции

- 💬 Общение с ИИ (Meta-Llama-3-70B)
- 💰 Покупка очков через платежную систему
- 📊 Отслеживание баланса очков
- 🔄 Ежедневный лимит бесплатных очков
- 👑 Админ-панель для управления пользователями

## Команды бота

- `/start` - Начать работу с ботом
- `/help` - Получить список команд
- `/points` - Проверить баланс очков
- `/admin` - Админ-панель (только для администраторов)

## Система очков

- 🆓 Ежедневный лимит: 50 бесплатных очков
- 🔄 Сброс лимита в полночь
- 💳 Возможность покупки дополнительных очков:
  - 100 очков - 100 RUB
  - 250 очков - 200 RUB
  - 500 очков - 350 RUB
  - 1000 очков - 600 RUB

## Технические требования

- Python 3.8+
- Библиотеки:
  - `python-telegram-bot`
  - `requests`
  - `sqlite3`

## Админ панель 
- В поле ADMINS = [], введите ваш id 
- Возможности администратора:
    - Добавление любого количества очков пользователю
    - Просмотр статистики

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-repo/ai-telegram-bot.git](https://github.com/Mewyer/AIBot)
   cd ai-telegram-bot
   ```
2. Установите зависимости 
    ```bash
    pip install -r requirements.txt
    ```
3. Установите ваши токены в поля:
    - DEEPINFRA_API_KEY = "" (Токен для Meta-Llama-3-70B берется из DeepInfra)
    - TOKEN = "" (Токен вашего телеграм бота)
4. Запустите бота 
    python main.py
